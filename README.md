# uav-safety-check
無人機飛手風險評估系統 (UAV Risk Assessment)

這是一個專為無人機勤務設計的專業風險評估表單，適用於火場、山域、水域搜救任務。

🌟 功能特點

自動計算邏輯：根據勾選的高/中風險項目，自動給出飛行決策建議。

響應式設計：支援手機、平板與電腦操作，介面自動適配不跑版。

直覺式 UI：大尺寸觸控按鈕，適合戶外高光環境快速點選。

無標籤設計：純淨介面，適合公務單位專業使用。

📋 使用規則

系統會依照以下邏輯自動判定：

✅ 安全可飛行：高風險 0、中風險 ≤ 2

⚠ 謹慎飛行：高風險 0、中風險 3 - 4

⚠️ 需特別注意：高風險 1、中風險 ≤ 2

❌ 建議不飛：累積風險過高（中風險 ≥ 5 或 高風險 ≥ 2）

🚀 如何使用

開啟本專案的 GitHub Pages 網址。

填寫基本任務資訊。

逐項點選風險等級。

查看底部自動生成的決策建議。

點擊「導出 PDF」進行任務存檔。
